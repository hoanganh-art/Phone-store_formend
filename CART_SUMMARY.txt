1. ✅ THÊM SẢN PHẨM VÀO GIỎ HÀNG
   📌 Hàm: addToCart(productId)
   📌 Vị trí: js/style.js (dòng 531)
   📌 Chức năng:
      • Lấy thông tin sản phẩm từ DOM
      • Lưu vào localStorage với key 'cart'
      • Tự động cập nhật số lượng nếu sản phẩm đã tồn tại
      • Hiển thị thông báo thành công

2. ✅ HIỂN THỊ GIỎ HÀNG (SIDEBAR)
   📌 Hàm: displayCart()
   📌 Vị trí: js/style.js (dòng 602)
   📌 Chức năng:
      • Lấy dữ liệu từ localStorage
      • Hiển thị danh sách sản phẩm
      • Hiển thị "Giỏ hàng trống" nếu không có sản phẩm
      • Tính và hiển thị tổng tiền
      • Có xử lý error với try-catch

3. ✅ MỞ/ĐÓNG GIỎ HÀNG
   📌 Vị trí: js/style.js (dòng 869-917)
   📌 Chức năng:
      • Click #cart-btn để mở giỏ
      • Click #close-cart để đóng giỏ
      • Click #continue-shopping để đóng
      • Click backdrop để đóng
      • Sidebar slide từ phải sang trái

4. ✅ CHỈNH SỬA SỐ LƯỢNG SẢN PHẨM
   📌 Hàm: 
      • changeQuantity(productId, change) - Thay đổi ±
      • setQuantity(productId, quantity) - Set cụ thể
   📌 Vị trí: js/style.js (dòng 667-700)
   📌 Chức năng:
      • Button +/- để tăng/giảm
      • Input để nhập trực tiếp
      • Tự động xóa nếu số lượng ≤ 0
      • Tự động cập nhật localStorage

5. ✅ XÓA SẢN PHẨM KHỎI GIỎ
   📌 Hàm: removeFromCart(productId)
   📌 Vị trí: js/style.js (dòng 703-712)
   📌 Chức náng:
      • Button trash icon trên mỗi sản phẩm
      • Xóa khỏi localStorage
      • Cập nhật hiển thị và badge
      • Hiển thị thông báo

6. ✅ CẬP NHẬT BADGE SỐ LƯỢNG
   📌 Hàm: updateCartCount()
   📌 Vị trí: js/style.js (dòng 592-599)
   📌 Chức năng:
      • Tính tổng số sản phẩm (tất cả số lượng)
      • Cập nhật #cart-count badge
      • Gọi tự động khi thêm/xóa/thay đổi

7. ✅ TÍNH TỔNG TIỀN
   📌 Hàm: formatPrice(price)
   📌 Vị trí: js/style.js (dòng 726-732)
   📌 Chức năng:
      • Tính tổng cho mỗi sản phẩm
      • Tính tổng cộng của giỏ
      • Format tiền theo chuẩn Việt Nam (VND)
      • Hiển thị trên #cart-total

8. ✅ LƯU DỮ LIỆU (localStorage)
   📌 Vị trí: Tất cả hàm
   📌 Chức năng:
      • Lưu dữ liệu vào localStorage['cart']
      • Format JSON array
      • Tự động load khi mở trang

💾 DỮ LIỆU LƯUTRỮ (localStorage)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Key: 'cart'

Cấu trúc dữ liệu:
[
    {
        id: 1,                      // ID sản phẩm
        name: "iPhone 15 Pro",      // Tên sản phẩm
        price: 32990000,            // Giá đơn vị
        image: "https://...",       // URL hình
        quantity: 2                 // Số lượng
    },
    ...
]

Cách kiểm tra:
1. Mở DevTools (F12)
2. Vào tab "Application"
3. Chọn "localStorage"
4. Tìm key "cart"
5. Xem dữ liệu JSON
