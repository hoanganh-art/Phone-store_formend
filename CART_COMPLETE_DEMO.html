📖 Hướng Dẫn Sử Dụng

1. HTML Elements cần có:

<button id="cart-btn"></button> <div id="cart-sidebar"> <div class="sidebar-backdrop"></div> <div class="sidebar-content"> <div id="cart-items"></div> <div id="cart-total"></div> <button id="close-cart"></button> <button id="continue-shopping"></button> </div> </div>

2. JavaScript Functions:

  • addToCart(productId) - Thêm sản phẩm vào giỏ
  • displayCart() - Hiển thị nội dung giỏ
  • updateCartCount() - Cập nhật badge số lượng
  • changeQuantity(productId, change) - Thay đổi số lượng
  • removeFromCart(productId) - Xóa sản phẩm

3. localStorage Structure:

// Giỏ hàng được lưu với key 'cart' localStorage.getItem('cart') // Returns: JSON array [ { id: 1, name: "iPhone 15", price: 32990000, image: "...", quantity: 1 }, ... ]
