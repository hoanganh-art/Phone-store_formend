🐛 DEBUGGING TIPS
───────────────────────────────────────────────────────────────────

Nếu gặp vấn đề:

1. Check Console (F12 → Console)
   - Có error gì không?
   - Có console.log nào không?

2. Check Elements (F12 → Elements)
   - Xem html structure có đúng không?
   - Xem CSS applied hay không?

3. Check Storage (F12 → Application → localStorage)
   - Xem dữ liệu 'cart' có không?
   - Format JSON đúng không?

4. Check Network (F12 → Network)
   - CSS/JS load đúng không?
   - API call thành công không?

5. Chạy test file:
   - CART_COMPLETE_DEMO.html
   - Nhấn "Kiểm Tra Hệ Thống"
   - Xem báo cáo chi tiết

6. Clear data & reload:
   - localStorage.clear()
   - Refresh F5
   - Thử lại từ đầu
